## 🎯 Apa itu Web Scanner?

**Web Scanner** adalah proyek web statis minimalis yang dibangun menggunakan **100% HTML**. Proyek ini dirancang sebagai fondasi atau *prototype* untuk aplikasi berbasis web yang membutuhkan fitur pemindaian (seperti QR Code, Barcode, atau dokumen) langsung melalui browser.

Dilengkapi dengan konfigurasi **GitHub Actions**, proyek ini siap di-deploy secara otomatis ke GitHub Pages, menjadikannya solusi yang cepat dan gratis untuk uji coba (*testing*) atau pengembangan lebih lanjut.

---

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---------|-------------|
| ⚡ **Super Ringan** | Dibangun murni dengan HTML tanpa framework atau dependensi eksternal yang berat |
| 🚀 **Deploy Otomatis** | Dilengkapi workflow GitHub Actions, cukup `git push` dan website langsung online |
| 📱 **Mobile-Friendly** | Struktur dasar yang siap dioptimalkan untuk tampilan perangkat seluler |
| 🛠️ **Mudah Dikembangkan** | Kode yang bersih dan terstruktur, mudah untuk ditambahkan JavaScript (misal: library `html5-qrcode`) |
| 🆓 **Gratis Selamanya** | Di-hosting di GitHub Pages tanpa biaya server atau domain |
